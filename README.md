⚽ Quiz de Lendas do Futebol: Messi, CR7 e Mbappé
Descrição
Este projeto é um quiz interativo desenvolvido para a plataforma Android com o objetivo de testar os conhecimentos dos fãs de futebol sobre três dos jogadores mais influentes da era moderna: Lionel Messi, Cristiano Ronaldo, e Kylian Mbappé.

O aplicativo (APK) conduz o usuário através de uma série de perguntas de diferentes níveis de dificuldade sobre a carreira, recordes e estatísticas dos atletas, ae, ao final, apresenta a performance total do usuário. O desenvolvimento foi realizado em Kotlin, utilizando o ambiente do Android Studio.

Funcionalidades

Interface Nativa: Design nativo Android para uma experiência de usuário fluida e responsiva.

Quiz com Múltiplas Perguntas: Questões de diferentes tipos 

Resultado Final Detalhado: Apresentação da performance total do usuário, com percentual de acerto.

Múltiplas Views: Utilização de elementos de interface como Utilização de EditText, Button, ImageView, RadioButton, CheckBox, Spinner e Switch.

Reiniciar o Quiz: Opção rápida para começar o questionário novamente.

⚙️ Tecnologias Utilizadas
Linguagem: Kotlin

Plataforma: Android Nativo

IDE: Android Studio

Build System: Gradle
