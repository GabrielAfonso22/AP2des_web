Projeto Android — repo gerado via assistente.

Instruções rápidas para subir no GitHub:

1. Se ainda não inicializou o Git:
   git init
2. Adicionar e commitar:
   git add .
   git commit -m "Initial commit"
3. Criar repositório no GitHub (site) ou usar gh CLI:
   gh repo create USER/REPO_NAME --public --source=. --remote=origin --push
4. Ou adicionar remoto manualmente:
   git remote add origin https://github.com/USER/REPO_NAME.git
   git branch -M main
   git push -u origin main

Se estiver usando autenticação HTTPS, o Git pedirá usuário e senha/token. Use um Personal Access Token (PAT) com escopo 'repo'.
